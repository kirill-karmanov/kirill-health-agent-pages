Kirill Health Agent

A personal AI-assisted wellness dashboard that turns user-authorized Google Health data into concise activity, sleep, recovery, and training summaries.

Purpose

  • Read personal Google Health information with explicit user authorization.
  • Generate private daily and weekly wellness summaries.
  • Support personal tracking and planning; it does not provide medical diagnosis or treatment.

Access model

This application is operated for a single owner. Google Health scopes are read-only. OAuth credentials are stored on a user-controlled server and are never published.
